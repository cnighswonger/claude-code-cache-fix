## What Is Correct

- The activation pattern is implemented correctly: `proxy/extensions.json` registers the extension with `"enabled": true`, while the runtime behavior is still gated by `CACHE_FIX_DUMP_MICROCOMPACT` and `CACHE_FIX_NORMALIZE_MICROCOMPACT` inside the hook ([proxy/extensions.json](proxy/extensions.json#L10), [proxy/extensions/microcompact-stability.mjs](proxy/extensions/microcompact-stability.mjs#L32), [proxy/extensions/microcompact-stability.mjs](proxy/extensions/microcompact-stability.mjs#L314)).
- The Mode A contract matches the approved directive: the default exact-pattern set is limited to the bare sentinel plus the constrained ISO-8601 timestamp form with optional milliseconds, and normalization only rewrites exact matches to the default canonical text unless overridden ([proxy/extensions/microcompact-stability.mjs](proxy/extensions/microcompact-stability.mjs#L81), [proxy/extensions/microcompact-stability.mjs](proxy/extensions/microcompact-stability.mjs#L191), [test/proxy-microcompact-stability.test.mjs](test/proxy-microcompact-stability.test.mjs#L113), [test/proxy-microcompact-stability.test.mjs](test/proxy-microcompact-stability.test.mjs#L168)).
- Raw-before-normalize is implemented correctly. The diagnostic record is built and written before any mutation, and `CACHE_FIX_DUMP_MICROCOMPACT_INCLUDE_NORMALIZED=1` adds `normalized_text` alongside the raw `sentinel_text` rather than replacing it ([proxy/extensions/microcompact-stability.mjs](proxy/extensions/microcompact-stability.mjs#L337), [proxy/extensions/microcompact-stability.mjs](proxy/extensions/microcompact-stability.mjs#L342), [test/proxy-microcompact-stability.test.mjs](test/proxy-microcompact-stability.test.mjs#L316), [test/proxy-microcompact-stability.test.mjs](test/proxy-microcompact-stability.test.mjs#L346)).
- The dump schema and privacy split are aligned with the directive for the built-in sentinel family: `exact_matches[]` and `partial_matches[]` are separate, Mode A stores full `sentinel_text`, Mode B stores only redacted prefix metadata, and session IDs are hashed before serialization ([proxy/extensions/microcompact-stability.mjs](proxy/extensions/microcompact-stability.mjs#L221), [proxy/extensions/microcompact-stability.mjs](proxy/extensions/microcompact-stability.mjs#L237), [proxy/extensions/microcompact-stability.mjs](proxy/extensions/microcompact-stability.mjs#L257), [test/proxy-microcompact-stability.test.mjs](test/proxy-microcompact-stability.test.mjs#L151), [test/proxy-microcompact-stability.test.mjs](test/proxy-microcompact-stability.test.mjs#L269)).
- Tool-result content shape coverage is solid for the shipped built-in path: the implementation handles both string and `[{type:"text"}]` content, leaves non-text array items alone, exposes the full telemetry surface on `ctx.meta.microcompactStats`, emits the stderr summary when it actually matched, and the full test suite passes locally (`627` passing) ([proxy/extensions/microcompact-stability.mjs](proxy/extensions/microcompact-stability.mjs#L129), [proxy/extensions/microcompact-stability.mjs](proxy/extensions/microcompact-stability.mjs#L277), [proxy/extensions/microcompact-stability.mjs](proxy/extensions/microcompact-stability.mjs#L296), [test/proxy-microcompact-stability.test.mjs](test/proxy-microcompact-stability.test.mjs#L273), [test/proxy-microcompact-stability.test.mjs](test/proxy-microcompact-stability.test.mjs#L373)).
- The PR comment's claimed order-350 tie with `deferred-tools-restore` is not active on this branch. `microcompact-stability` is the only extension registered at order 350 in `proxy/extensions.json`, so its required position between `tool-input-normalize` (340) and `cache-control-normalize` (400) is satisfied as implemented ([proxy/extensions.json](proxy/extensions.json#L9), [proxy/extensions.json](proxy/extensions.json#L10), [proxy/extensions.json](proxy/extensions.json#L11)).

## Blockers

- Custom sentinel families do not get the required Mode B handling. The approved directive says `CACHE_FIX_MICROCOMPACT_SENTINEL_PATTERN_<N>` patterns are subject to the same Mode A / Mode B treatment as the defaults, but the implementation's partial-match path is hardcoded to `SENTINEL_PREFIX = "[Old tool result content cleared"` and never derives a prefix from custom patterns. As a result, a custom sentinel can normalize on exact match yet its prefix-only variant is silently dropped instead of being captured redacted in `partial_matches[]` ([proxy/extensions/microcompact-stability.mjs](proxy/extensions/microcompact-stability.mjs#L95), [proxy/extensions/microcompact-stability.mjs](proxy/extensions/microcompact-stability.mjs#L111), [proxy/extensions/microcompact-stability.mjs](proxy/extensions/microcompact-stability.mjs#L172), [docs/directives/proxy-microcompact-cache-stability.md](docs/directives/proxy-microcompact-cache-stability.md#L108), [docs/directives/proxy-microcompact-cache-stability.md](docs/directives/proxy-microcompact-cache-stability.md#L186)). The test file currently masks this gap: "5b" still exercises the built-in prefix family, not a custom-prefix Mode B path ([test/proxy-microcompact-stability.test.mjs](test/proxy-microcompact-stability.test.mjs#L240)).

## What Needs Attention

- The docs currently describe custom patterns more broadly than the code actually supports. Once the implementation is fixed, the docs and test 5b should be tightened around a real custom-family prefix-only example so this contract cannot regress silently ([README.md](README.md#L186), [docs/extension-impact-guide.md](docs/extension-impact-guide.md#L186), [test/proxy-microcompact-stability.test.mjs](test/proxy-microcompact-stability.test.mjs#L240)).

## Recommendations

- Extend partial-match detection so each custom Mode A family can also produce a corresponding redacted Mode B capture path, or narrow the directive and docs if that broader contract is no longer desired. The current state is inconsistent.
- Replace test 5b with a case that proves a custom sentinel family is captured redacted on prefix-only mismatch, not just the built-in `[Old tool result content cleared` family.

## Bottom Line

Revise before approval. The core built-in microcompact path is implemented cleanly and the branch passes its full test suite, but the custom-pattern contract approved at directive stage is not actually met: custom sentinel families can match exactly, yet their prefix-only variants are not captured in Mode B at all.
