## Scope

Per the lead's release-discipline directive, this smoke test validates the v3.7.1 `bootstrap-defense` extension in a container-runtime environment (Docker `node:22-alpine`) using the repo's existing `Dockerfile`. The unit + integration test suite (871/871) covers correctness in-process; the smoke test catches Node/filesystem/path/runtime assumptions that only show up in a container.

The CC binary itself is not exercised — the fake upstream stubs the bootstrap response shapes expected per the directive's surface contract. This is appropriate because the cache-fix proxy's contract is "given a bootstrap response, behave as specified" — the upstream behavior on the CC side is owned by Anthropic, not by this proxy.

## Test rig

- **Fake upstream** at host `0.0.0.0:9802` (`/tmp/cf-fake-upstream.mjs`): a tiny Node HTTP server with a `__ctl__/shape` endpoint to switch between response shapes per section

  - Run with `--add-host=host.docker.internal:host-gateway` so the container can reach the host fake upstream
  - `CACHE_FIX_PROXY_UPSTREAM=http://host.docker.internal:9802`
  - `-v /tmp/cf-smoke-logs/:/home/node/.claude` to capture the JSONL audit log on the host for assertion
  - `-p 127.0.0.1:9881:9801` to publish the proxy on a host port that won't collide with anything else
